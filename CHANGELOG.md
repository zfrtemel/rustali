# Changelog

All notable changes to Rustali are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com) and
[Conventional Commits](https://www.conventionalcommits.org).


### Features

- Error negotiation, default middleware stack, Ctx, config layout
- POCO entities over SeaORM, typed Query, migrations and console commands
- Attribute routing, filter pipeline, authorization gate
- Askama/Tera view layer, validation, sessions, flash and CSRF
- Batteries-included authentication
- Code-first diff migrations (EF Core style)
- Ecosystem packages (cache/mail/queue), test kit, and the rustali CLI
